## 完整日志 ZIP

入口：**设置 → 运行日志 → 导出完整日志 ZIP（不脱敏）**。

- Android 使用应用私有目录的持久日志，旧 `runtime.log.1` 等历史文件一并导出；取消原来的 1 MB 覆盖限制。
- iOS 使用 Application Support 的持久日志，取消原来只在内存保留 2000 条的限制；ZIP64 流式导出，保留原始字节。
- Flutter console、框架异常、未捕获异常，原生协议请求/响应及异常，原生事件、新闻 HTTP 请求/响应，教务网页控制台与返回 HTML 均进入日志；Android 额外保存本进程可读取的 logcat。
- 文本不脱敏；二进制协议体以 Base64 保留原始内容。ZIP 导出前等待已排队的 Flutter 日志写入，两端均调用系统分享功能。
- 日志重启后保留最近滚动 24 小时，过期自动清理，不自动上传。用户主动清除日志会删除本机历史记录。
- 旧实现已经覆盖或仅保存在已结束进程内存中的日志无法恢复；系统沙箱之外的操作系统日志不属于应用可收集范围。

## 验证与边界

原生模拟服务器与 Flutter 回归测试验证 Cookie 跳转、HTML 学期识别、课表、评价字段及失败反馈、查询接口选择、评价状态刷新和 ZIP 导出交互。ZIP 测试验证重启保留、超过旧限制的内容、历史文件、中文、未脱敏 Cookie/密码、二进制数据和解压 CRC。

学校当前公开教务登录页可正常访问；真实账号登录后的九项业务操作仍需 Android 真机验收，自动测试不能代替学校账号与实际业务权限。

当前环境中，修改前代码同样存在 3 个 golden 截图失败和 1 个贴吧图片滑动测试失败，已通过临时目录中原始 HEAD 的测试确认。成绩页面因本次新增详情与原始网页入口，已验证并更新其截图基准；另外 2 个既有截图差异和贴吧图片滑动失败保留，未掩盖全套测试结果。

最终检查：Dart analyze 无问题；Android 两个 flavor 各 20 项原生测试通过；Swift 核心 20 项测试通过；相关 Flutter 测试 26 项通过。完整 Flutter 测试仍存在上面记录的 3 项既有失败。两个 Android arm64 调试 APK 均成功构建；iOS 原生 UI 层未进行完整 Xcode 打包。

## 操作审计与最近一天保留

全局记录 Flutter 页面打开/关闭和导航返回、主标签与贴吧分区切换、点击/滚动、文本输入和选择控件变化、Riverpod 状态变化与异常。原生 API、偏好写入、课表保存/历史清理、AI 会话保存/删除、附件导入/删除及 AI 工具调用记录参数、关联 ID、开始、结果或失败；课表保存记录原版本和新版本。AI HTTP 和图片下载进入统一传输日志，流式响应逐块记录并传播取消信号。

保留范围为滚动 24 小时。原生存储首次写入及后续每分钟清理过期记录，恢复到前台和导出时触发清理；休眠期间不执行后台计时任务。旧多行记录随首行时间一并清理，旧无时间戳文件迁移时使用文件修改时间。导出不按条数或大小截断。

WebView 记录导航、页面内容、资源加载元数据、网页交互以及诊断脚本安装后发起的 fetch/XHR 请求和响应。浏览器内部请求（初始导航、子资源、跨域受限数据等）及 Android 系统 DownloadManager 不提供完整原始请求/响应内容；这些入口记录应用可获取的信息，不能视为全量网络抓包。系统外部应用操作也不在本应用可观测范围内。
